            // 04 Spotlight: Rec Room Revival
          

          recroom-backend.md
        


        

          

            🚧 In progress
            
A from-scratch backend for Rec Room

            

              The official servers won't be around forever, so I'm rebuilding the server side from the ground up — reverse-engineered from the game itself, not from docs.
            

            
    
              
  • ASP.NET Core backend with a custom SignalR replacement for Photon
    • 
              
  • Reverse-engineered via IL2CPP analysis and Wireshark packet capture
    • 
              
  • Runs on an Oracle Cloud Ampere A1 ARM VM, game traffic over UDP 5058
    • 
              
  • Deployed with GitHub Actions CI/CD
    • 
            

            

              ASP.NET Core
              SignalR
              C#
              Oracle A1 ARM
              UDP 5058
